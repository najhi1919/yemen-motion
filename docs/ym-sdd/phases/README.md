# فهرس توثيق المراحل

يوفر هذا المجلد سجلًا تشغيليًا دائمًا للمراحل منذ المناقشة والتخطيط، مرورًا بالمحطات والتحقق، وحتى الإغلاق. يبدأ ملف المرحلة قبل التنفيذ، وتبقى سجلات القرارات والتقدم تراكمية لا تُعاد كتابتها لإخفاء التاريخ.

## قاعدة الحالة

حالة المرحلة لا تُستنتج من نسبة جزئية أووجود كود. تُحدّث وفق الأدلة المسجلة في ملف التقدم ومعايير القبول، ولا تصبح `closed` إلا بعد اكتمال بوابة الإغلاق واعتماد المستخدم.
